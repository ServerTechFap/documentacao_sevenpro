# SevenPro - Banco de Dados

Script SQL para criação do banco de dados **SevenPro**.

⚠️ **Atenção**: Este script **remove o banco existente** (caso haja) e cria tudo do zero.

Inclui tabelas para:

- Usuários, perfis, inscrições
- Eventos, apresentações, hackathons
- Logs, arquivos e e-mails

Requisitos: **MySQL 8+**
